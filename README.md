# Онлайн-чат на сайте с ответами из Telegram

Замена Jivo для https://praktik-home.ru/. Как это работает:

- на сайте справа внизу кнопка чата; через 4 секунды рядом всплывает «Здравствуйте! Чем могу помочь?»;
- посетитель пишет, и бот создаёт в вашей Telegram-группе **отдельную тему** «Посетитель #N» (в первом сообщении указана страница, с которой пишут);
- вы отвечаете прямо в этой теме: текстом, ссылками, фото, файлами. Ответ сразу появляется у посетителя в окне чата;
- переписка сохраняется: если посетитель вернётся на сайт с того же браузера, он увидит историю и новые ответы (на кнопке будет счётчик).

Всё работает на вашем сервере, бесплатно, без внешних библиотек: нужен только Node.js 18 или новее.

## Файлы

| Файл | Что это |
|---|---|
| `server.js` | сервер чата и бот |
| `public/widget.js` | виджет, который подключается на сайт |
| `ai.js` | бот на нейросети (ответы по базе знаний, сбор заявок) |
| `simple.js` | простой бот без нейросети (ключевые слова, заявка по сценарию) |
| `scrape.js` | сборщик базы знаний с сайта |
| `knowledge/` | база знаний ассистента (файлы `.md`) |
| `.env.example` | пример настроек (скопировать в `.env`) |
| `install.sh` | установка на сервер одной командой |
| `nginx-chat.conf` | настройка nginx для поддомена |

## Шаг 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Придумайте имя (например, «Практик Home чат») и логин, который заканчивается на `bot` (например, `praktik_home_chat_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAAbbb...`. Сохраните его, никому не показывайте.
4. Там же отправьте `/setprivacy`, выберите бота и нажмите **Disable**, чтобы бот видел ваши ответы в группе.

## Шаг 2. Создайте группу для переписки

1. В Telegram создайте новую группу (например, «Чат с сайта»), добавьте туда бота.
2. Откройте настройки группы → **Темы** (Topics) → включите. Группа станет форумом.
3. В настройках группы → **Администраторы** → добавьте бота администратором и включите право **«Управление темами»**.
4. Если хотите, чтобы отвечали и коллеги, просто добавьте их в эту группу.

### Узнайте ID группы

1. Напишите в группе любое сообщение (например, «тест»).
2. Откройте в браузере, подставив свой токен:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найдите `"chat":{"id":-100...` — это число (вместе с минусом) и есть **GROUP_ID**.

Делайте это **до** запуска сервера: после запуска сервер сам забирает сообщения, и эта ссылка будет показывать пустой список.

## Шаг 3. Поддомен

DNS-запись `chat.prometgs.ru → 111.88.118.56` у вас уже есть. В Cloudflare оставьте режим **DNS only** (серое облако), иначе не выдастся сертификат.

## Шаг 4. Установка на сервер (Ubuntu 24.04)

Подключитесь к серверу (`ssh root@111.88.118.56`) и выполните:

```bash
apt-get update && apt-get install -y git
git clone https://github.com/egcherepita-rgb/chat /opt/chat
cd /opt/chat
bash install.sh chat.prometgs.ru
```

Если репозиторий приватный, `git clone` попросит логин и пароль: в поле пароля нужен токен GitHub (Settings → Developer settings → Personal access tokens), обычный пароль не подойдёт. Проще на время сделать репозиторий публичным: в коде нет секретов, токен бота хранится только в файле `.env` на сервере.

Скрипт спросит токен бота и ID группы, затем сам установит Node.js, nginx, настроит автозапуск и HTTPS. В конце он напишет «Готово!» и покажет строку для вставки на сайт.

Проверка: откройте `https://chat.prometgs.ru/health`, должно показать `{"ok":true}`.

Логи, если что-то не так: `journalctl -u site-chat -f`

### Если хостер блокирует Telegram

Если в логах `Telegram: fetch failed`, а `curl -m 10 https://api.telegram.org` зависает, нужен прокси. Бесплатно это делается через Cloudflare Worker (Workers & Pages → Create application → Hello World, имя `tg-proxy`) с таким кодом:

```js
export default {
  async fetch(req) {
    const url = new URL(req.url);
    url.hostname = 'api.telegram.org';
    return fetch(new Request(url, req));
  }
};
```

Затем добавьте адрес Worker в `.env` и перезапустите чат:

```bash
echo 'TG_API=https://tg-proxy.ВАШ-АККАУНТ.workers.dev' >> /opt/chat/.env
systemctl restart site-chat
```

> Если на сервере уже работает другой веб-сервер (например, Apache) на 80/443 порту, скрипт не сможет запустить nginx. В этом случае напишите мне, подстроим.

## Шаг 5. Уберите Jivo и подключите чат на сайте (1С-Битрикс)

1. **Удалите Jivo.** Обычно он стоит одним из двух способов:
   - как модуль: *Администрирование → Marketplace → Установленные решения* → JivoSite → «Удалить»;
   - как код в шаблоне: *Настройки → Настройки продукта → Сайты → Шаблоны сайтов* → ваш шаблон → «Изменить», найдите в `footer.php` (или `header.php`) блок со словом `jivo` (`<script src="//code.jivo.ru/widget/...">`) и удалите его.
2. **Вставьте одну строку** туда же, перед `</body>`:

```html
<script src="https://chat.prometgs.ru/widget.js" async></script>
```

3. Сохраните шаблон и сбросьте кэш (*Настройки → Настройки продукта → Автокеширование → Очистить*).

### Настройка внешнего вида (по желанию)

```html
<script src="https://chat.prometgs.ru/widget.js" async
  data-title="Практик HOME"
  data-greeting="Здравствуйте! Чем могу помочь?"
  data-color="#255f6c"
  data-position="right"></script>
```

`data-color` — основной цвет, `data-accent` — второй цвет градиента, `data-button-color` — цвет кнопки чата, `data-position` — `right` или `left`. `data-hours="8-18"` и `data-days="1-5"` — когда чат виден (по Москве, по умолчанию пн–пт с 8:00 до 18:00).

## Шаг 6. Проверка

Откройте сайт, напишите в чат «тест». В группе появится тема «Посетитель #1». Ответьте в теме, и ответ появится на сайте в течение секунды.

## Как отвечать

- Отвечайте **внутри темы** посетителя. Сообщения в «Общей» теме никуда не уходят.
- Поддерживаются текст с форматированием и ссылками, фото, файлы, видео, голосовые, стикеры. Файлы больше 20 МБ посетитель не сможет скачать (ограничение Telegram для ботов), такие лучше давать ссылкой.
- Если удалить тему, а посетитель напишет снова, бот создаст новую.

## Что важно знать

- Посетитель может отправлять только текст.
- Посетитель узнаётся по браузеру: с другого устройства это будет новый диалог.
- Хранятся последние 500 сообщений на посетителя. Для резервной копии достаточно копировать `data.json`.
- Переписка хранится в `/opt/chat/data.json`.
- Обновить чат после изменений в репозитории: `cd /opt/chat && git pull && systemctl restart site-chat`.
- Изменить токен или группу: `nano /opt/chat/.env`, затем `systemctl restart site-chat`.

## Бот-помощник в чате

Бот сам отвечает посетителям по базе знаний (товары, цены, контакты с вашего сайта). Если посетитель хочет расчёт, проект, замер или просит перезвонить, бот спрашивает **имя, телефон (или другой контакт) и город**, и в тему посетителя приходит карточка:

```
🔥 Новая заявка с сайта
👤 Имя: Иван
📞 Контакт: +7 900 111-22-33
🏙 Город: Казань
📝 Что нужно: гардеробная 2 м
```

Карточка закрепляется в теме, тема переименовывается в «🔥 Иван · Казань · #12», а копия карточки со ссылкой на переписку приходит в «Общую» тему группы.

**Вы видите всё:** каждый ответ бота дублируется в тему с пометкой 🤖.

**Как перехватить диалог:** просто ответьте в теме. Бот сразу замолкает в этом диалоге (и напишет об этом в теме). Команды в теме посетителя:

- `/bot` — вернуть бота в этот диалог;
- `/stop` — выключить бота в этом диалоге, ничего не отвечая посетителю.

Если менеджер молчит 12 часов, бот снова начинает отвечать (настройка `AI_RESUME_HOURS`). Если посетитель просит живого человека, бот замолкает сам и пишет в тему «🙋 Посетитель просит живого менеджера».

### Два режима, оба бесплатные

| | Простой бот (`BOT_MODE=simple`) | Нейросеть (`BOT_MODE=ai`) |
|---|---|---|
| Стоимость | бесплатно, без регистраций | бесплатно в пределах лимита Google Gemini |
| Как отвечает | по ключевым словам: находит раздел базы знаний или товар и показывает его | понимает вопрос своими словами и отвечает как человек |
| Заявка | по сценарию: имя → контакт → город | в живом диалоге |
| Что нужно | ничего | ключ Google AI Studio (регистрация через VPN) |

Если нейросеть недоступна (кончился дневной лимит, сбой), за неё автоматически отвечает простой бот, так что посетитель без ответа не останется.

**Про бесплатные нейросети честно:**
- **Google Gemini** (рекомендую): бесплатный тариф с запасом для чата на сайте, хорошо говорит по-русски. Минусы: из России регистрироваться нужно через VPN, запросы идут через ваш Cloudflare Worker (как у Telegram), а на бесплатном тарифе Google может использовать переписку для улучшения своих моделей. Лимиты смотрите на https://aistudio.google.com/rate-limit
- **Groq** (`LLM_PROVIDER=groq`): тоже бесплатно, но лимит маленький (около 8 000 токенов в минуту), а один ответ с базой знаний тратит несколько тысяч. Подходит, если посетителей мало.
- **GigaChat** от Сбера бесплатен только физлицам и только для личного некоммерческого использования, для сайта компании это нарушение условий.
- **Своя нейросеть на сервере** бесплатна, но для нормального русского языка нужен сервер с 16 ГБ памяти или видеокартой: на обычном VPS ответ будет идти минуту и больше.
- **YandexGPT** (`LLM_PROVIDER=yandex`) — платно, но без VPN и прокси; если понадобится, переключается одной строкой.

### Шаг 1. Обновите чат и соберите базу знаний

```bash
cd /opt/chat && git pull
node scrape.js
```

`scrape.js` обойдёт сайт (несколько минут) и создаст `knowledge/site.md` (контакты, доставка, оплата и другие страницы) и `knowledge/catalog.json` (все товары с ценами и размерами). Повторяйте, когда на сайте меняются цены или товары.

### Шаг 2а. Простой бот (без нейросети)

Допишите в `.env` одну строку и перезапустите:

```bash
echo 'BOT_MODE=simple' >> /opt/chat/.env
systemctl restart site-chat
journalctl -u site-chat -n 20 --no-pager
```

В логе должно быть `Бот: простой режим без нейросети`. Готово.

### Шаг 2б. Нейросеть Gemini (бесплатно)

1. **Ключ.** Включите VPN, откройте https://aistudio.google.com/apikey, войдите Google-аккаунтом и нажмите **Create API key**. Скопируйте ключ (начинается на `AIza`). VPN после этого больше не нужен.
2. **Прокси.** Google, как и Telegram, недоступен с сервера, поэтому запросы пойдут через ваш Cloudflare Worker `tg-proxy`. Откройте его в Cloudflare (**Workers & Pages → tg-proxy → Edit code**), замените код на этот и нажмите **Deploy**. Telegram продолжит работать как раньше:

```js
// Прокси для чата: Telegram (как раньше) и нейросети по адресу https://worker/<хост>/<путь>
const ALLOWED = ['generativelanguage.googleapis.com', 'api.groq.com', 'openrouter.ai'];

export default {
  async fetch(req) {
    const url = new URL(req.url);
    const [, first, ...rest] = url.pathname.split('/');
    if (ALLOWED.includes(first)) {
      url.hostname = first;
      url.pathname = '/' + rest.join('/');
    } else {
      url.hostname = 'api.telegram.org';
    }
    return fetch(new Request(url, req));
  }
};
```

3. **Настройки.** Допишите в `/opt/chat/.env` (`nano /opt/chat/.env`, сохранить: Ctrl+O, Enter, Ctrl+X):

```
BOT_MODE=ai
LLM_PROVIDER=gemini
LLM_API_KEY=AIza...ваш-ключ
LLM_PROXY=https://tg-proxy.evgnasa.workers.dev
```

4. Перезапустите и проверьте лог:

```bash
systemctl restart site-chat
journalctl -u site-chat -n 20 --no-pager
```

Должно быть `Бот: нейросеть gemini-2.5-flash`. Напишите на сайте «Сколько стоит гардеробная?», бот ответит через несколько секунд. Если в теме появилось «⚠️ Нейросеть недоступна (HTTP 400/403 …)», проверьте ключ и код Worker. Модель можно сменить строкой `LLM_MODEL=...` (список моделей в Google AI Studio). Если Google отвечает «User location is not supported», значит запрос всё же определился как российский: напишите мне, настроим другой маршрут, а пока работает простой бот.

### Как дополнять базу знаний

Всё, что лежит в `/opt/chat/knowledge/` в файлах `.md`, бот перечитывает сам (перезапуск не нужен).

- `01-osnovnoe.md` — основные сведения (лежит в репозитории, правьте его на GitHub, потом `git pull`).
- Свои ответы пишите в **новый файл** прямо на сервере, например `nano /opt/chat/knowledge/02-nashi-otvety.md`. Каждый ответ — отдельный раздел с заголовком `## ` и строкой ключевых слов (по ним простой бот находит ответ; нейросеть читает весь текст):

```
## Доставка
Ключевые слова: доставка, привезти, сроки, транспортная компания
По Москве доставляем за 1–2 дня, стоимость ... По России отправляем транспортной компанией ...

## Гарантия
Ключевые слова: гарантия, брак, возврат
...
```

  Чем подробнее (доставка, оплата, гарантия, сроки, бесплатен ли замер и проект, адреса шоурумов), тем лучше ответы.
- `site.md` и `catalog.json` перезаписываются командой `node scrape.js`, вручную их не правьте.

Автообновление каталога раз в неделю (по понедельникам в 6:00):

```bash
(crontab -l 2>/dev/null; echo '0 6 * * 1 cd /opt/chat && node scrape.js >/dev/null 2>&1') | crontab -
```

### Чат круглосуточно

Пока менеджеры не в сети, отвечать может бот. Чтобы чат был виден всегда, добавьте в код на сайте:

```html
<script src="https://chat.prometgs.ru/widget.js" async data-hours="0-24" data-days="1-7"></script>
```

### Выключить бота

Допишите в `.env` строку `BOT_MODE=off` и выполните `systemctl restart site-chat`. Чат продолжит работать как раньше, с живыми ответами.
