# Онлайн-чат на сайте с ответами из Telegram

Замена Jivo для https://praktik-home.ru/. Как это работает:

- на сайте справа внизу кнопка чата; через 4 секунды рядом всплывает «Здравствуйте! Чем могу помочь?»;
- посетитель пишет, и бот создаёт в вашей Telegram-группе **отдельную тему** «Посетитель #N» (в первом сообщении указана страница, с которой пишут);
- вы отвечаете прямо в этой теме: текстом, ссылками, фото, файлами. Ответ сразу появляется у посетителя в окне чата;
- переписка сохраняется: если посетитель вернётся на сайт с того же браузера, он увидит историю и новые ответы (на кнопке будет счётчик).

Всё работает на вашем сервере, бесплатно, без внешних библиотек: нужен только Node.js 18 или новее.

## Файлы

| Файл | Что это |
|---|---|
| `server.js` | сервер чата и бот |
| `public/widget.js` | виджет, который подключается на сайт |
| `.env.example` | пример настроек (скопировать в `.env`) |
| `install.sh` | установка на сервер одной командой |
| `nginx-chat.conf` | настройка nginx для поддомена |

## Шаг 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Придумайте имя (например, «Практик Home чат») и логин, который заканчивается на `bot` (например, `praktik_home_chat_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAAbbb...`. Сохраните его, никому не показывайте.
4. Там же отправьте `/setprivacy`, выберите бота и нажмите **Disable**, чтобы бот видел ваши ответы в группе.

## Шаг 2. Создайте группу для переписки

1. В Telegram создайте новую группу (например, «Чат с сайта»), добавьте туда бота.
2. Откройте настройки группы → **Темы** (Topics) → включите. Группа станет форумом.
3. В настройках группы → **Администраторы** → добавьте бота администратором и включите право **«Управление темами»**.
4. Если хотите, чтобы отвечали и коллеги, просто добавьте их в эту группу.

### Узнайте ID группы

1. Напишите в группе любое сообщение (например, «тест»).
2. Откройте в браузере, подставив свой токен:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Найдите `"chat":{"id":-100...` — это число (вместе с минусом) и есть **GROUP_ID**.

Делайте это **до** запуска сервера: после запуска сервер сам забирает сообщения, и эта ссылка будет показывать пустой список.

## Шаг 3. Поддомен

DNS-запись `chat.prometgs.ru → 111.88.118.56` у вас уже есть. В Cloudflare оставьте режим **DNS only** (серое облако), иначе не выдастся сертификат.

## Шаг 4. Установка на сервер (Ubuntu 24.04)

Подключитесь к серверу (`ssh root@111.88.118.56`) и выполните:

```bash
apt-get update && apt-get install -y git
git clone https://github.com/egcherepita-rgb/chat /opt/chat
cd /opt/chat
bash install.sh chat.prometgs.ru
```

Если репозиторий приватный, `git clone` попросит логин и пароль: в поле пароля нужен токен GitHub (Settings → Developer settings → Personal access tokens), обычный пароль не подойдёт. Проще на время сделать репозиторий публичным: в коде нет секретов, токен бота хранится только в файле `.env` на сервере.

Скрипт спросит токен бота и ID группы, затем сам установит Node.js, nginx, настроит автозапуск и HTTPS. В конце он напишет «Готово!» и покажет строку для вставки на сайт.

Проверка: откройте `https://chat.prometgs.ru/health`, должно показать `{"ok":true}`.

Логи, если что-то не так: `journalctl -u site-chat -f`

### Если хостер блокирует Telegram

Если в логах `Telegram: fetch failed`, а `curl -m 10 https://api.telegram.org` зависает, нужен прокси. Бесплатно это делается через Cloudflare Worker (Workers & Pages → Create application → Hello World, имя `tg-proxy`) с таким кодом:

```js
export default {
  async fetch(req) {
    const url = new URL(req.url);
    url.hostname = 'api.telegram.org';
    return fetch(new Request(url, req));
  }
};
```

Затем добавьте адрес Worker в `.env` и перезапустите чат:

```bash
echo 'TG_API=https://tg-proxy.ВАШ-АККАУНТ.workers.dev' >> /opt/chat/.env
systemctl restart site-chat
```

> Если на сервере уже работает другой веб-сервер (например, Apache) на 80/443 порту, скрипт не сможет запустить nginx. В этом случае напишите мне, подстроим.

## Шаг 5. Уберите Jivo и подключите чат на сайте (1С-Битрикс)

1. **Удалите Jivo.** Обычно он стоит одним из двух способов:
   - как модуль: *Администрирование → Marketplace → Установленные решения* → JivoSite → «Удалить»;
   - как код в шаблоне: *Настройки → Настройки продукта → Сайты → Шаблоны сайтов* → ваш шаблон → «Изменить», найдите в `footer.php` (или `header.php`) блок со словом `jivo` (`<script src="//code.jivo.ru/widget/...">`) и удалите его.
2. **Вставьте одну строку** туда же, перед `</body>`:

```html
<script src="https://chat.prometgs.ru/widget.js" async></script>
```

3. Сохраните шаблон и сбросьте кэш (*Настройки → Настройки продукта → Автокеширование → Очистить*).

### Настройка внешнего вида (по желанию)

```html
<script src="https://chat.prometgs.ru/widget.js" async
  data-title="Практик HOME"
  data-greeting="Здравствуйте! Чем могу помочь?"
  data-color="#255f6c"
  data-position="right"></script>
```

`data-color` — основной цвет, `data-accent` — второй цвет градиента, `data-button-color` — цвет кнопки чата, `data-position` — `right` или `left`. `data-hours="8-18"` и `data-days="1-5"` — когда чат виден (по Москве, по умолчанию пн–пт с 8:00 до 18:00).

## Шаг 6. Проверка

Откройте сайт, напишите в чат «тест». В группе появится тема «Посетитель #1». Ответьте в теме, и ответ появится на сайте в течение секунды.

## Как отвечать

- Отвечайте **внутри темы** посетителя. Сообщения в «Общей» теме никуда не уходят.
- Поддерживаются текст с форматированием и ссылками, фото, файлы, видео, голосовые, стикеры. Файлы больше 20 МБ посетитель не сможет скачать (ограничение Telegram для ботов), такие лучше давать ссылкой.
- Если удалить тему, а посетитель напишет снова, бот создаст новую.

## Что важно знать

- Посетитель может отправлять только текст.
- Посетитель узнаётся по браузеру: с другого устройства это будет новый диалог.
- Хранятся последние 500 сообщений на посетителя. Для резервной копии достаточно копировать `data.json`.
- Переписка хранится в `/opt/chat/data.json`.
- Обновить чат после изменений в репозитории: `cd /opt/chat && git pull && systemctl restart site-chat`.
- Изменить токен или группу: `nano /opt/chat/.env`, затем `systemctl restart site-chat`.
